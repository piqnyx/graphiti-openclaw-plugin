# Формат JSON для `add_memory` (Graphiti OpenClaw plugin)

Согласовано: 2026-08-14. Пока не устареет — это канон.

## Зачем это нужно

Плагин буферизует сообщения из OpenClaw-сессии и периодически отправляет их в
Graphiti через `add_memory`. Мы передаём данные в **своём JSON-формате**, потому
что это даёт:

- **правильные имена акторов** в графе (а не безликие `User` / `Assistant`);
- больше контекста для построения связей между сущностями;
- реальные роли участников диалога.

## Структура JSON

```json
{
  "participants": {
    "user": "Виктор",
    "assistant": "Краб"
  },
  "messages": [
    {
      "role": "user",
      "text": "Привет"
    },
    {
      "role": "assistant",
      "text": "Привет, Вит"
    }
  ]
}
```

### Поля

| Поле | Обязательно | Описание |
|---|---|---|
| `participants.user` | да | Каноническое имя пользователя |
| `participants.assistant` | да | Каноническое имя ассистента |
| `messages[].role` | да | `user` или `assistant` |
| `messages[].text` | да | Текст сообщения |

## Чего НЕТ в формате (и почему)

### `dateTime` — нет
- Дефолтный промпт `extract_json` запрещает извлекать даты/время/таймстампы.
- Graphiti сам строит темпоральность через `reference_time` эпизода.
- Наши даты система всё равно проигнорирует, поэтому слать их бессмысленно.

### `custom_extraction_instructions` — нет
- Мы остаёмся на **дефолтном промпте** Graphiti, кастомный не используем.

## Параметры запроса `add_memory`

| Параметр | Значение |
|---|---|
| `source` | `json` |
| `reference_time` | Текущее время коммита батча (ISO-8601) |
| `group_id` | `agentId` |
| `saga` | `sessionKey` |

### Про `custom_extraction_instructions` в конфиге
Принято решение кастомный промт **не делать вовсе** — поле не включаем в запрос.

## Имена акторов и алиасы

Канонические имена берутся **из конфига** при формировании JSON.
К каждому участнику — массив алиасов-регулярок, которые заменяются на
каноническое имя **в момент формирования JSON** (до отправки в Graphiti).

```json
{
  "participants": [
    {
      "role": "user",
      "name": "Виктор",
      "aliases": ["Ви", "Вит", "Виктор", "Витя"]
    },
    {
      "role": "assistant",
      "name": "Краб",
      "aliases": ["Краб", "Крабушек"]
    }
  ]
}
```

Зачем: Graphiti видит только канонические имена, в графе один узел `Виктор`,
а не пять разных `Ви` / `Вит` / `Витя`. Алиасы не засоряют граф.

Регулярки компилируются **один раз при старте плагина**, а не на каждое сообщение.

## Примечание про разброс времени в батче

Таймер коммита 15 минут на неактивность, лимит батча 50 сообщений.
Теоретически можно растянуть батч на ~12 часов (по 1 сообщению каждые 14:59),
при этом `reference_time` будет = время коммита, что исказит временную линию.

Принято: **не чиним.** Это теоретический edge case, в среднем человек так не
пишет. Если на практике увидим искажение темпоральности — тогда отдельная задача
(возможно переход на `source=message` со своим таймстампом у каждого сообщения,
но ценой меньшего контекста связей).
